# Install 安装后的目录结构说明

> **重要说明**：本文档描述的是**用户项目安装后**的目录结构。  
> 在 Co-OmniSpec 开发环境中，源文件位于 `src/agent/` 和 `src/specify/`，  
> 安装脚本会将它们复制到用户项目的 `.{agent}/`（如 `.cursor/`、`.claude/` 等）和 `.specify/` 目录下。

## 一、安装命令示例

```bash
# 安装到目标项目
./install.sh claude /path/to/your-project

# 或安装为其他 agent 名称
./install.sh cursor /path/to/your-project
./install.sh flow /path/to/your-project
```

## 二、安装后的目录结构

安装完成后，目标项目根目录下会新增两个目录：

```
your-project/
├── .{agent}/              # Agent 配置目录（如 .claude, .cursor, .flow）
│   ├── agents/            # AI Agent 定义文件
│   ├── commands/           # 命令定义文件
│   └── skills/             # Skill 技能定义
│
└── .specify/              # Specify 工具目录
    ├── config              # 配置文件
    ├── memory/             # 项目记忆/章程
    ├── metamodel/          # 元模型模板
    ├── scripts/            # 脚本工具集
    └── templates/          # 模板文件
```

## 四、目录说明

### 4.1 `.{agent}/` 目录

**作用**: 存放 AI Agent 的配置和命令定义

- **`agents/`**: 定义各种 AI Agent 的行为和职责
- **`commands/`**: 定义用户可执行的命令（如 `/omni.reverse`）
- **`skills/`**: 定义技能模板，支持按项目定制

**特点**:
- 目录名以点号开头（如 `.claude`, `.cursor`），表示隐藏目录
- 支持多个 agent 并存（如同时有 `.claude` 和 `.cursor`）
- 所有 agent 使用相同的源目录 `src/agent/`

### 4.2 `.specify/` 目录

**作用**: 存放工具脚本、模板和配置

- **`scripts/`**: 可执行的工具脚本（Bash/PowerShell/Python）
- **`templates/`**: 文档生成模板
- **`metamodel/`**: 元模型定义模板
- **`memory/`**: 项目记忆和章程
- **`config`**: 配置文件（可选）

**特点**:
- 脚本文件会自动设置可执行权限
- 支持跨平台（Bash/PowerShell）
- 模板支持自定义和项目特定配置

## 五、安装后的使用

### 5.1 基本使用

安装完成后，可以在项目中使用以下功能：

1. **AI Agent 命令**: 在 AI 对话中使用各种 omni 命令
   - **Reverse 反构命令**:
     - `/omni.reverse` - 反构主命令
     - `/omni.reverse.interfaces` - 接口反构
     - `/omni.reverse.entities` - 实体反构
     - `/omni.reverse.functions` - 功能反构
     - `/omni.reverse.scenarios` - 场景反构
     - `/omni.reverse.on-demand` - 按需反构
   - **其他 Omni 命令**:
     - `/omni.analyze` - 分析
     - `/omni.design` - 设计
     - `/omni.implement` - 实现
     - `/omni.specify` - 规范
     - `/omni.tasks` - 任务
     - `/omni.clarify` - 澄清
     - `/omni.checklist` - 检查清单
     - `/omni.constitution` - 章程
2. **脚本工具**: 直接调用 `.specify/scripts/` 下的脚本
3. **模板定制**: 在 `.specify/templates/` 中自定义模板

### 5.2 路径引用

安装脚本会自动处理路径引用：

安装脚本会自动将 `src/agent/` 的内容复制到目标 agent 目录（如 `.claude`、`.cursor`、`.flow` 等），所有 agent 使用相同的源目录。

### 5.3 配置文件

可以在 `.specify/config` 文件中配置：

```bash
# 文档目录配置
DOC_DIR=omni-doc

# 其他配置...
```

## 六、目录大小估算

| 目录 | 大小估算 | 说明 |
|-----|---------|------|
| `.{agent}/` | ~500KB - 1MB | 主要是 Markdown 文件 |
| `.specify/` | ~2MB - 5MB | 包含脚本、模板、Python 代码 |
| **总计** | **~3MB - 6MB** | 相对轻量级 |

---

## 七、注意事项

1. **隐藏目录**: `.{agent}/` 和 `.specify/` 都是隐藏目录（以点号开头）
2. **Git 忽略**: 建议将这两个目录添加到 `.gitignore`（如果不需要版本控制）
3. **权限**: 脚本文件会自动设置可执行权限
4. **增量更新**: agent 目录采用增量覆盖，会保留目标中的额外文件
5. **完整替换**: specify 目录采用完整替换，确保与源目录一致
