
### 表一：aia_metric_fact（AI 架构指标事实明细表）
**🏗️ 新表结构设计**

| 顶层字段名 (分类) | 数据类型 | 必填 | 内部 JSON 结构定义 (Schema) | 变更策略说明 |
| :--- | :---: | :---: | :--- | :--- |
| **identity_info***(身份)* | JSON | ✅ | ```json<br>{<br>  "skill_id": "string",        // 指标唯一标识<br>  "arch_dimension": "string"  // 架构主维度    <br>}``` | **极低变更**。仅当需要增加新的身份标识（如 user_id）时扩展。 |
| **execution_ctx***(执行上下文)* | JSON | ✅ | ```json<br>{<br>  "skill_version": "string",     // 指标技能版本号<br>  "scan_mode": "enum",         // 扫描模式：increment/full<br>  "execute_status": "enum",    // 执行状态<br>  "start_time": "timestamp",   // 扫描开始时间<br>  "end_time": "timestamp",     // 扫描结束时间<br>  "duration_ms": "integer"     // 执行耗时（毫秒）<br>}``` | **低变更**。主要记录运行状态，除非扫描器增加新的运行时元数据（如 host_ip）。 |
| **core_metrics***(核心指标)* | JSON | ✅ | ```json<br>{<br>  "total_score": "double",           // 综合得分 0~100<br>  "confidence_score": "double",      // 置信度得分 0~1<br>  "total_violation_count": "integer",// 总违规数<br>  "p0_violation_count": "integer",   // P0 级别违规数<br>  "p1_violation_count": "integer"    // P1 级别违规数（可选扩展）<br>}``` | **中变更**。提取了最关键的聚合数值。若新增评级（如 P3），直接在此 JSON 中加键即可，无需改表。 |
| **evaluation_details***(评估详情)* | JSON | ⚠️ | ```json<br>{<br>  "score_detail": { <br>    // 子维度得分明细（无限扩展）<br>    "directory_single_score": 0.85,<br>    "module_cohesion_score": 0.80,<br>    "file_single_score": 0.79<br>  },      <br>  "confidence_detail": { <br>    // 置信度因子明细<br>    "structure_confidence": 0.8,<br>    "semantic_confidence": 0.75,<br>    "context_confidence": 0.7<br>  }<br>}``` | **高变更 / 高频扩展**。原 metric_result 的主体。任何 AI 模型维度的增减都只在此处变动。 |
| **violation_records***(违规记录)* | JSON | ⚠️ | ```json<br>{<br>  "level_summary": {"P0":0,"P1":3},  // 违规级别统计<br>  "violation_infos": [ <br>    {<br>      "type": "string",        // 违规类型<br>      "level": "string",       // 违规等级<br>      "scope_path": "string",  // 作用域路径<br>      "resources": [],         // 关联资源列表<br>      "suggestion": "string"   // 优化建议<br>    }<br>  ],<br>  "exempt_infos": []            // 豁免列表<br>}``` | **极高变更**。原 violation_info 的主体。违规类型、修复建议格式、豁免理由等随时可能增加新字段。 |
| **scan_statistics***(扫描统计)* | JSON | ⚠️ | ```json<br>{<br>  "total_units": {},      // 总扫描单元统计<br>  "violation_units": {},  // 违规单元统计<br>  "valid_units": {}       // 有效扫描单元<br>}``` | **高变更**。扫描粒度（文件 / 函数 / 类）变化时，只需修改此 JSON 内部的 Key。 |
