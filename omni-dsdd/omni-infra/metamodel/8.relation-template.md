# 关系模板

关系文件用于定义不同元素之间的关联关系，采用 JSON 格式存储。

## 文件格式

关系文件是一个 JSON 数组，每个元素表示一个源元素到多个目标元素的关系。

```json
[
  {
    "source": "[SOURCE-ID]",
    "targets": [
      "[TARGET-ID-1]",
      "[TARGET-ID-2]"
    ]
  }
]
```

## 字段说明

- **source**: 源元素的ID，格式为 `[TYPE]-XXX`（如 `FUNC-001`、`ENTITY-001`、`API-001`）
- **targets**: 目标元素的ID数组，每个目标ID格式为 `[TYPE]-XXX`

## 文件名格式

关系文件的命名格式为：`{source_type}-{target_type}.json`

其中：
- `source_type`: 源元素类型，如 `function`、`logic_entity`、`requirement`、`scenario` 等
- `target_type`: 目标元素类型，如 `interface`、`logic_entity`、`function` 等

**示例：**
- `function-interface.json`: 功能到接口的关系（FUNC → API）
- `function-logic_entity.json`: 功能到逻辑实体的关系（FUNC → ENTITY）
- `logic_entity-interface.json`: 逻辑实体到接口的关系（ENTITY → API）
- `requirement-scenario.json`: 需求到场景的关系（REQ → SCN）
- `scenario-requirement.json`: 场景到需求的关系（SCN → REQ）

## 文件位置

关系文件应放在系统规格说明的 `relations/` 目录下，例如：
- `omni-doc/specs/relations/function-interface.json`
- `omni-doc/specs/relations/function-logic_entity.json`

## 使用说明

1. **创建关系文件**：根据需要定义的关系类型，创建对应的关系文件
2. **定义关系**：在 JSON 数组中添加关系条目，每个条目包含一个源元素和多个目标元素
3. **ID 格式**：确保源元素和目标元素的 ID 格式正确，并与实际文档中的 ID 保持一致
4. **关系方向**：关系是有方向的，`A-B.json` 表示从 A 到 B 的关系，`B-A.json` 表示从 B 到 A 的关系

## 示例

### 功能到接口的关系（function-interface.json）

```json
[
  {
    "source": "FUNC-001",
    "targets": [
      "API-007",
      "API-008",
      "API-011"
    ]
  },
  {
    "source": "FUNC-002",
    "targets": [
      "API-003",
      "API-005"
    ]
  }
]
```

### 功能到逻辑实体的关系（function-logic_entity.json）

```json
[
  {
    "source": "FUNC-001",
    "targets": [
      "ENTITY-003"
    ]
  },
  {
    "source": "FUNC-002",
    "targets": [
      "ENTITY-001",
      "ENTITY-002",
      "ENTITY-003"
    ]
  }
]
```

### 逻辑实体到接口的关系（logic_entity-interface.json）

```json
[
  {
    "source": "ENTITY-001",
    "targets": [
      "API-003",
      "API-004"
    ]
  },
  {
    "source": "ENTITY-002",
    "targets": [
      "API-003",
      "API-012"
    ]
  }
]
```

## 注意事项

- 关系文件中的 ID 必须与实际文档中的 ID 保持一致
- 同一个源元素可以关联多个目标元素
- 关系是单向的，如果需要双向关系，需要创建两个关系文件
- JSON 文件必须符合 JSON 格式规范，注意逗号和括号的使用
