# Clarify 自动决策指令（Workflow 编排注入）

本阶段在 **SDD 自动工作流**（express / standard / deep）中执行，用户不可用。你必须：

1. **禁止**等待用户输入；**禁止**使用 `AskUserQuestion` 或任何需用户回复的交互
2. 对 `clarify` SKILL.md 步骤 4 中的**每个**澄清问题：
   - 按 SKILL.md 要求分析各选项，确定**推荐选项**（多项选择）或**建议答案**（简答题）
   - **立即自动采纳**该推荐/建议作为最终答案（等价于用户回复 `recommended` / `yes` / `suggested`）
   - **不得**输出选项表格后暂停等待确认
3. 每题采纳后立即执行步骤 5 增量集成，继续下一题，直至达到 5 题上限、无有效问题，或所有关键模糊性已解决
4. 完成报告须注明 **模式: 自动决策（workflow）**，并列出所有自动采纳的 Q→A 摘要

目标：无人值守完成 clarify，**所有问题均自动决策为推荐选项**。
