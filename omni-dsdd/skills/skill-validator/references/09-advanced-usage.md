# 1. 高级用法检查

检查技能中高级功能的使用情况，这些功能可以增强技能的能力，但也需要正确的配置和使用。

## 1.1 动态上下文注入检查

### 1.1.1 `!`命令` 语法检查
- [ ] **`!`命令` 语法格式正确** [必选项]：确保动态上下文注入语法正确
  - 验证方法：检查 `!`命令` 的使用
  - 正确格式：`!`命令` 或 `!`command arguments``
  - 错误示例：
    - `!command`（缺少反引号）
    - `command``（缺少感叹号）
    - `!"command"`（使用了双引号）
  - 正确示例：
    ```markdown
    - 代码变更：!`gh pr diff`
    - 评论内容：!`gh pr view --comments`
    ```

- [ ] **Shell 命令安全性** [必选项]：检查注入的 Shell 命令是否安全
  - 验证方法：分析命令的安全风险
  - 危险命令：
    - `rm`、`rm -rf`（删除文件）
    - `sudo`（提升权限）
    - `dd`（直接磁盘操作）
    - `mkfs`（文件系统操作）
    - `chmod 777`（权限过宽）
  - 安全建议：
    - 避免使用危险命令
    - 使用参数限制和验证
    - 提供清晰的命令说明

- [ ] **Shell 命令必要性** [可选项]：确保动态注入是必要的
  - 验证方法：分析是否真的需要动态内容
  - 适用场景：
    - 拉取实时数据（git log, gh pr diff）
    - 获取系统状态
    - 读取实时配置
  - 不适用场景：
    - 静态内容
    - 不需要实时信息的内容

- [ ] **Shell 命令有说明** [必选项]：动态注入的命令应有说明
  - 验证方法：检查命令附近是否有说明
  - 错误示例：命令无任何说明
  - 正确示例：
    ```markdown
    ## 拉取请求上下文

    以下信息将通过 Shell 命令动态获取：
    - 代码变更：!`gh pr diff`
    - 评论内容：!`gh pr view --comments`
    - 变更文件：!`gh pr diff --name-only`

    注意：这些命令需要 gh CLI 工具和适当的权限配置。
    ```

### 1.1.2 动态内容依赖检查
- [ ] **动态内容依赖说明** [必选项]：说明动态内容所需的依赖
  - 验证方法：检查是否有依赖说明
  - 依赖类型：
    - 系统工具（gh, git）
    - 权限要求（API 令牌）
    - 网络连接
  - 错误示例：需要 gh CLI 但未说明
  - 正确示例：
    ```markdown
    注意：本技能需要以下依赖：
    - gh CLI 工具（GitHub 命令行）
    - GitHub API 访问权限
    - 网络连接到 GitHub
    ```

### 1.1.3 动态内容错误处理
- [ ] **动态内容有错误处理** [必选项]：说明命令失败时的处理方式
  - 验证方法：检查是否有错误处理说明
  - 错误示例：无错误处理说明
  - 正确示例：
    ```markdown
    错误处理：
    - 如果 gh 命令失败，会显示错误信息
    - 如果没有 GitHub 权限，提示用户配置认证
    - 如果网络不可用，使用缓存数据（如有）
    ```

## 1.4 上下文加载规则检查

### 1.4.1 上下文加载说明
- [ ] **上下文加载规则有说明** [必选项]：说明技能的上下文加载行为
  - 验证方法：检查是否有加载规则说明
  - 加载规则：
    - 默认配置：常驻描述，调用后加载完整内容
    - disable-model-invocation: true：不常驻描述，仅手动调用加载
    - disable-model-invocation: false 或省略：常驻描述，可自动调用
    - user-invocable: false：常驻描述，调用后加载完整内容
    - **被其他 skill 调用的技能：必须允许自动调用（disable-model-invocation: false 或省略）**
  - 错误示例：无加载规则说明
  - 正确示例：
    ```markdown
    ## 上下文加载

    本技能配置为 disable-model-invocation: true：
    - 技能简介不会常驻上下文
    - 仅在手动调用时加载完整内容
    - 适合需要用户确认的操作
    ```
  - 被调用技能的正确示例：
    ```markdown
    ## 上下文加载

    本技能被其他技能调用：
    - 技能简介常驻上下文
    - 可被自动调用加载
    - 提供基础能力支持
    ```

### 1.4.2 子代理加载说明
- [ ] **子代理加载有说明** [必选项]：说明子代理的内容加载行为
  - 验证方法：检查是否有子代理加载说明
  - 说明内容：
    - 预加载技能的子代理会在启动时注入完整技能内容
    - 与常规会话的按需加载不同
  - 错误示例：使用子代理但无加载说明
  - 正确示例：
    ```markdown
    ## 子代理说明

    本技能使用 context: fork 在子代理中运行：
    - 子代理启动时会注入完整技能内容
    - 与常规会话的按需加载不同
    - 适合长时间运行的任务
    ```
