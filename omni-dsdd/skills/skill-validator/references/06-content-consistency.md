# 1. 内容类型一致性

检查技能的配置、调用方式与内容类型的一致性，确保三者匹配。

## 1.1 配置与内容一致性

- [ ] **配置与内容类型一致** [必选项]：确保配置反映内容类型
  - 验证方法：比较配置和内容
  - 一致性检查：
    - 参考类 → 内容为知识性说明
    - 任务类 → 内容为操作性说明
  - 错误示例：
    - 配置显示为任务类（如设置disable-model-invocation: true），但内容为参考类
    - 配置显示为参考类，但内容为任务类
  - 正确示例：配置和内容类型完全一致
  - 检查要点：
    - 如果技能主要是提供知识、规范、说明，配置不应禁止自动调用
    - 如果技能主要是执行操作、流程、任务，配置应考虑禁止自动调用

- [ ] **内容特征符合类型定义** [可选项]：内容特征与识别的类型匹配
  - 验证方法：检查内容的实际特征
  - 参考类内容特征：
    - 提供背景知识
    - 说明规范和标准
    - 解释设计模式
    - 描述业务规则
  - 任务类内容特征：
    - 提供明确的步骤
    - 有具体的操作流程
    - 有预期的输出
    - 有验证方法
  - 错误示例：特征与类型定义不符
  - 正确示例：内容特征完全符合类型定义

## 1.2 调用方式与内容匹配

- [ ] **调用方式与内容匹配** [必选项]：调用方式应适合内容类型和调用关系
  - 验证方法：检查调用权限配置和技能调用关系
  - 匹配规则：
    - 参考类：适合自动调用，用于补充知识
    - 任务类：适合手动调用，执行操作
    - **被其他 skill 调用的技能：必须允许自动调用**
  - 错误示例：
    - 任务类技能允许自动调用
    - 参考类技能禁止自动调用
    - **被其他技能调用的技能禁止自动调用**
  - 正确示例：调用方式与内容类型和调用关系完全匹配
  - 配置检查：
    - 参考类技能通常设置 `disable-model-invocation: false` 或省略
    - 任务类技能通常设置 `disable-model-invocation: true`（除非被其他技能调用）
    - **被其他技能调用的技能必须设置 `disable-model-invocation: false` 或省略**

- [ ] **user-invocable 配置合理** [必选项]：用户可调用性配置正确
  - 验证方法：检查user-invocable字段设置
  - 配置建议：
    - 参考类技能：可以设置为true，适合自动调用
    - 任务类技能：应设置为true，需要用户手动调用
  - 错误示例：配置与内容类型不匹配
  - 正确示例：
    ```yaml
    # 参考类技能
    disable-model-invocation: false
    user-invocable: true

    # 任务类技能
    disable-model-invocation: true
    user-invocable: true
    ```

## 1.3 description与内容一致性

- [ ] **description与内容类型一致** [必选项]：描述应反映实际的内容类型
  - 验证方法：比较description与实际内容
  - 检查要点：
    - 参考类技能的description应强调"说明"、"规范"、"知识"
    - 任务类技能的description应强调"执行"、"处理"、"操作"
  - 错误示例：
    - description说"代码生成规范"但内容是"代码生成流程"
    - description说"部署应用"但内容是"部署规范说明"
  - 正确示例：description准确反映内容类型

- [ ] **description关键词匹配内容类型** [必选项]：关键词应与内容类型匹配
  - 验证方法：检查description中的关键词
  - 参考类关键词：说明、规范、指南、知识、参考、定义
  - 任务类关键词：执行、处理、操作、部署、生成、转换、运行
  - 错误示例：关键词与内容类型不符
  - 正确示例：关键词准确反映内容类型
