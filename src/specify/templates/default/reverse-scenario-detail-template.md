**使用说明：**
- **id**: 场景ID，格式为 `SCN-XXX`，其中 `XXX` 为三位数字（如 `001`, `002`, `003`...），必须与文件名中的数字保持一致
- **name**: 场景名称，应简洁明了地描述场景的核心内容
- **brief**: 场景简要描述，一句话概括场景的核心内容和目的，用于文档索引和快速浏览
- **description**: 场景详细描述，说明场景的业务背景、触发条件、主要参与者和预期结果（可选字段，用于元模型和文档索引）
- **文件名格式**: `SCN-XXX-场景名称.md`，其中 `XXX` 为三位数字，与 `id` 中的数字保持一致
- **内容格式**: 
  - 使用PlantUML序列图描述交互流程
  - 参与者命名应清晰，逻辑实体应标注实体ID（格式：`实体名称\nENTITY-XXX`）
  - 使用 `== 流程名称 ==` 分隔不同的流程
  - 使用 `alt/else/end` 描述条件分支
  - 关键步骤说明用于补充序列图中难以表达的细节
  - 异常场景用于描述错误处理和边界情况
